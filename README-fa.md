# نظرات مستقل کوارتز (Quartz Standalone Comments)

این پروژه یک سیستم ثبت نظر را به [Quartz](https://quartz.jzhao.xyz/) اضافه می‌کند. مخزن اصلی را می‌توانید در اینجا پیدا کنید: https://github.com/dlnorman/standalone-comments.

من چندین تغییر برای بهبود سازگاری و قابلیت استفاده برای وب‌سایت‌های کوارتز ایجاد کردم. اکنون این سیستم به کمک Cloudflare Workers و D1 بسیار ساده‌تر و خودکار شده است!

> ✅ سازگار با کوارتز ورژن 5

## ویژگی‌ها

![تصویر](comments.webp)

- 🌍 پشتیبانی چندزبانه (انگلیسی و فارسی، قابل توسعه از طریق i18n)
- 😀 واکنش‌ها (Reactions) با ۱۰ گزینه ایموجی برای پست‌ها و نظرات
- 👤 پشتیبانی از Gravatar با آواتار پیش‌فرض خودکار
- 💬 ویجت آخرین نظرات
- 🛠️ پنل مدیریت برای مشاهده و مدیریت نظرات
- 📦 پشتیبانی از درون‌ریزی و برون‌بری (Import/Export) داده‌ها
- 🛡️ محافظت در برابر هرزنامه (Spam) و سیستم نظارت
- 📧 اعلان‌های ایمیلی برای نظرات جدید (نیاز به پیکربندی دارد)

## راهنمای نصب و استقرار

این راهنما برای افراد مبتدی نوشته شده است! ما از **Cloudflare Workers** (برای اجرای کد) و **Cloudflare D1** (برای ذخیره نظرات) استفاده خواهیم کرد.

### پیش‌نیازها

1. **Node.js**: مطمئن شوید که Node.js را نصب کرده‌اید. می‌توانید آن را از [nodejs.org](https://nodejs.org/) دانلود کنید.
2. **حساب کاربری کلودفلر**: یک حساب کاربری رایگان در [Cloudflare](https://dash.cloudflare.com/sign-up) ایجاد کنید.
3. این مخزن را دانلود کرده و یک ترمینال در داخل پوشه پروژه باز کنید.

### مرحله ۱: ورود به کلودفلر

این دستور را در ترمینال خود اجرا کنید تا به حساب کلودفلر خود متصل شوید:

`npx wrangler login`

یک پنجره مرورگر باز می‌شود که از شما می‌خواهد Wrangler را مجاز کنید.

### مرحله ۲: نصب و راه‌اندازی

بسته‌های مورد نیاز را نصب کنید:

`npm install`

اکنون، اسکریپت راه‌اندازی خودکار را اجرا کنید. این اسکریپت به طور خودکار پایگاه داده را ایجاد می‌کند، آن را پیکربندی می‌کند و از شما می‌خواهد یک رمز عبور برای ادمین انتخاب کنید:

`npm run setup`

*(نکته: اگر پیش از این دیتابیس را ایجاد کرده‌اید یا این دستور را دوباره اجرا کنید، اسکریپت به درستی دیتابیس قبلی را شناسایی کرده و به شما امکان می‌دهد بدون از دست رفتن داده‌ها، رمز عبور خود را بروزرسانی کنید.)*

### مرحله ۳: توسعه محلی (اختیاری)

اگر می‌خواهید سرور را پیش از استقرار به صورت محلی آزمایش کنید، اجرا کنید:

`npm run dev`

سرور شما در آدرس `http://127.0.0.1:8787` در دسترس خواهد بود. برای مشاهده پنل مدیریت به صورت محلی می‌توانید به آدرس `http://127.0.0.1:8787/admin/index.html` بروید.

### مرحله ۴: استقرار در محیط عملیاتی

هنگامی که آماده بودید، سرور نظرات را در کلودفلر مستقر کنید:

`npm run deploy`

ترمینال یک URL عمومی به شما می‌دهد (مانند `https://standalone-comments-server.<your-username>.workers.dev`). این **آدرس بک‌اند (Backend URL)** شما است.

<br>

## نصب افزونه کوارتز

دستور زیر را در داخل پروژه کوارتز خود اجرا کنید:

`npx quartz plugin add github:fardm/quartz-standalone-comments`

پس از نصب، فایل `quartz.config.yaml` را باز کرده و افزونه را پیکربندی کنید. مقدار `backendUrl` را برابر با آدرس سروری که پس از استقرار دریافت کرده‌اید قرار دهید:

```yaml
- source: github:fardm/quartz-standalone-comments
  enabled: true
  options:
    backendUrl: https://standalone-comments-server.<your-username>.workers.dev
  layout:
    position: afterBody
    priority: 100
```

سرور پیش‌نمایش محلی کوارتز را راه‌اندازی کنید (`npx quartz build --serve`) تا نظرات را در عمل ببینید!

<br>

## دسترسی به پنل مدیریت

برای مدیریت نظرات و تغییر تنظیمات، به URL مستقر شده خود بروید و `/admin/index.html` را به انتهای آن اضافه کنید.

برای مثال:
`https://standalone-comments-server.<your-username>.workers.dev/admin/index.html`

با استفاده از رمز عبوری که در مرحله `npm run setup` انتخاب کرده‌اید، وارد شوید.
